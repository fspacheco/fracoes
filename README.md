# Frações interativas (rascunho)

Página educacional e interativa sobre frações, em português do Brasil, adaptada das lições de frações do LearnFree (GCFGlobal).
Feita só com HTML, CSS e JavaScript — sem dependências, sem build. Funciona offline e no celular.

**Arquivos:** `index.html` (página), `style.css` (visual), `script.js` (interatividade e ilustrações SVG).

## Acessibilidade
- Paleta Okabe-Ito, segura para daltonismo; toda cor vem acompanhada de um padrão (listras, pontos, grade, ╳).
- Feedback com ícone e texto (✓ / ✗ / !), nunca só com cor.
- Botão “Alto contraste”, navegação por teclado, alvos de toque ≥ 44 px.
